*   **HTML:** Estruturação semântica de páginas web.
*   **CSS:** Estilização, layouts responsivos (Flexbox/Grid) e animações.
*   **JavaScript:** Manipulação do DOM, eventos e consumo de APIs.

## 🔧 Como Executar os Projetos Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com
   ```
2. Navegue até a pasta do projeto desejado:
   ```bash
   cd nome-do-projeto
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador ou utilize a extensão **Live Server** no VS Code.
